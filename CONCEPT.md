# AdvancedTech Evolution — концепция (Forge 1.12.2)

## 1. Энергия
| Тир | Макс. передача (FE/t) | Буфер машины | Потери кабеля/блок | Кабель |
|-----|----------------------|--------------|--------------------|--------|
| LV  | 32   | 4 000   | 0.20 % | медь, изоляция резина |
| MV  | 128  | 16 000  | 0.15 % | олово/сталь |
| HV  | 512  | 64 000  | 0.10 % | серебро/электрум |
| EV  | 2048 | 256 000 | 0.05 % | сверхпроводник (квантовое ядро) |

* Внутренняя валюта — **FE** (Forge Energy). IC2 EU подключается мостом (1 EU = 4 FE, настраивается).
* Кабель = TileEntity с буфером и пропускной способностью тира. Каждый шаг по сети теряет `lossPerBlock`.
  Если за тик через кабель проходит > `maxTransfer`, растёт счётчик перегрузки → кабель нагревается → плавится (блок исчезает, поджигает соседей).
* Мосты: тир-трансформаторы LV↔MV↔HV↔EV (повышающий/понижающий) — без них высокий тир сожжёт низкий.

## 2. Машины
Корпус: **Базовый → Улучшенный → Индустриальный → Квантовый** (апгрейд кликом корпусом по машине).

| Корпус | Скорость | Охлаждение | Слоты апгрейдов |
|--------|----------|-----------|-----------------|
| 0 | ×1.0 | ×1.0 | 0 |
| 1 | ×1.5 | ×1.5 | 1 |
| 2 | ×2.5 | ×2.5 | 2 |
| 3 | ×4.0 | ×4.0 | 3 |

**Тепло:** работа греет (`энергия/16` за тик), блок остывает пропорционально разнице с окружающей средой.
≥100 — перегрев (машина встаёт до 70), ≥150 — взрыв. Охлаждение: радиаторы-апгрейды, соседние блоки воды/льда, хладагент в слоте.

## 3. Исследования
* **Книга Инженера** = книга + красная пыль + железный слиток (shapeless, JSON-рецепт готов).
* Очки: первый крафт предмета (+5), первое убийство нового моба (+10), первая добыча редкой руды (+8), убийство босса (+100). Множитель в конфиге.
* Дерево (реализовано в `ResearchRegistry`):

```
basic_machines (0) ─┬─ electric_circuits (25) ─┬─ pollution_control (80)
                    │                          └─ automation (120, +processing) ─ mv_tier (150) ─ hv_tier (300) ─ quantum_tech (600)
                    └─ processing (30) ────────┘
```
* Блокировки: `ResearchRegistry.lock("modid:item", "research_id")` (генераторы → `electric_circuits`). Можно вызывать из CraftTweaker.
* Данные игрока — capability `IResearchData` (NBT, переживает смерть, синхронизируется пакетом).

## 4. Книга Рецептов (GUI) — спецификация
Вкладки: **Базовые механизмы / Генераторы / Обработка / Автоматизация**. Страница рецепта = сетка 3×3 + описание.
Кнопка «Подсветить предметы» — для каждого ингредиента сравнить с `mc.player.inventory`; есть → зелёная рамка, нет → красная, количество в тултипе. Рецепты, требующие неизученного исследования, показываются с замком.
Данные страниц — JSON в `assets/advancedtech/guide/*.json` (вкладка → список рецептов → ключ описания в .lang).

## 5. Мобы
| Моб | Спавн | Особенности | Дроп |
|-----|-------|-------------|------|
| Робот-охранник | рядом с заброшенными лабораториями (структура + `EntityAIAttackRanged`) | лазерный снаряд | микросхемы |
| Мутант сточных вод | болота + загрязнённые чанки | яд (Poison) | биомасса |
| Дрон-добытчик | пещеры, нейтральный | взлом инструментом → GUI программы (список точек/режим «копать область») | — |
| **Механический Голем** (босс) | заброшенные заводы | фазы: лазер → ракеты (ударные снаряды) → ремонт дронами | квантовое ядро |

## 6. Уникальные фичи
* **Загрязнение:** значение на чанк (capability чанка). Генераторы без фильтра добавляют `+N/мин`, фильтр снижает. Порог → растения гибнут (случайные `randomTick`), далее мутанты.
* **Логические трубы:** узлы с приоритетом по сторонам, фильтры по предметам, режимы Round-Robin / Приоритет / Overflow. Сеть кэшируется (BFS при изменении топологии), не по тикам.
* **Мультиблоки:** дробилка 3×3×3, термоядерный реактор 5×5×5 с контроллером (GUI: плазма/магнитное поле/охлаждение). Паттерн проверяется `BlockPattern`-подобным шаблоном при клике по контроллеру.
* **Квантовый сундук:** frequency-ключ (цвет×3 + владелец); общий `ItemStackHandler` в `WorldSavedData` по ключу.

## 7. Конфиг и совместимость
* `ATConfig` (`config/AdvancedTechEvolution.cfg`): сложность рецептов 0–2, тепло, потери, загрязнение, исследования, множитель очков, список «редких руд».
* CraftTweaker: `@ZenClass("mods.advancedtech.Research")` с методами `lock`, `addNode`, `addCost` — через `@Optional.Method(modid="crafttweaker")`.
* IC2: мост `@Optional.Interface(iface="ic2.api.energy.tile.IEnergySink", modid="ic2")` на кабеле и машинах.
